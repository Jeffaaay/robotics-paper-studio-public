# Repository guidance

- Preserve the distinction between source facts, user notes, and assistant synthesis.
- Do not claim that a paper was read, reproduced, or understood without direct evidence.
- Keep publication and social posting manual: drafts require human review and approval.
- Never commit credentials, private task identifiers, local absolute paths, full chat exports, or employer source code.
- Prefer primary sources and record dates, experimental denominators, limitations, and reproduction status.
- Run the repository tests before committing workflow changes.
