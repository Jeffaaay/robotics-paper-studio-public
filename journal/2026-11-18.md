## 1. UniGarmentManip · 把示范抓取点迁移到新衣服 · 首选

UniGarmentManip: A Unified Framework for Category-Level Garment Manipulation via Dense Visual Correspondence

**IEEE/CVF CVPR 2024，pp. 16340–16350；DOI 10.1109/CVPR52733.2024.01546**  
同行评审会议 · 2024

[阅读论文 ↗](<https://arxiv.org/html/2405.06903v1>)　 ·　 [作者 / 出版方页面 ↗](<https://warshallrho.github.io/unigarmentmanip/>)　 ·　 [项目页面 ↗](<https://warshallrho.github.io/unigarmentmanip/>)　 ·　 [作者代码 ↗](<https://github.com/luhr2003/UniGarmentManip>)

> **想弄懂：** 衣服变形、袖子变长后，如何找到示范中对应的抓取点？为什么还需要针对折叠任务微调？

**为什么适合你**  
首选。适合 OpenArm 双臂叠 T-shirt：先研究如何将示范的抓放点对应到不同形状、变形的衣服，再考虑执行。CVPR 的视觉表示论文，有双 Panda 实验；对 OpenArm 的适配属于待验证建议。

**从这里开始**  
arXiv v1：§3 与 Fig. 2 → §4.2 的两类对应关系 → §4.4–4.5 的任务适配和抓放点迁移 → §5.7 / Fig. 8 / Table 5。第二遍再看 §4.3 的困难点修正与 §5.6 消融。

**阅读时间**  
AI 估计：第一轮 35–50 分钟；对比学习与点云基础需要时另补，不要求一次读完。

## 2. 丢包下的自触发 MPC · 控制与通信时刻一起规划 · 备选

Self-triggered MPC robust to bounded packet loss via a min-max approach

**IEEE 61st Conference on Decision and Control (CDC) 2022，pp. 7670–7675；DOI 10.1109/CDC51059.2022.9992581**  
同行评审会议 · 2022

[阅读论文 ↗](<https://arxiv.org/html/2204.00339v2>)　 ·　 [作者 / 出版方页面 ↗](<https://www.ist.uni-stuttgart.de/research/publications/>)

> **想弄懂：** 既要限制通信频率，又可能连续丢包，控制器怎样同时选择控制输入和下次更新时间？

**为什么适合你**  
AMR 时序备选。帮助梳理“这次发什么”和“下次何时更新”的关系，以及丢包后执行器实际保持的旧输入如何进入预测。适合读控制与通信假设；对 AMR 的工程迁移仍需验证。

**从这里开始**  
扩展稿 v2：§II / Fig. 1 → Eq. (4) token bucket → Eq. (5)–(6) 旧输入保持 → §III / Eq. (8) 最坏丢包预测 → §IV / Figs. 2–3。随后读 Assumptions 1–2、Theorem 1；证明可留到第二轮。

**阅读时间**  
AI 估计：机制与假设 30–45 分钟；LMI、终端集合和完整证明另需 45–60 分钟。
